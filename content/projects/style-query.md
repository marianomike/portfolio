StyleQuery brings container and media queries to Roblox UI, so an interface adapts to its layout size, aspect ratio and player settings without any scripts.

## What shipped

- **StyleQuery**, now available in every experience.
- **Preferred text size** as a built-in query, with selectors for four text-size tiers, so UI can respond to a player's text size setting.
- **Folders** under style sheets and style rules, with queries kept in their own folder automatically.
- **Better Style Editor search** that indexes every style rule, and selectors that fill in when a built-in device query is added.
- **Multiple and nested pseudo-instances**, like several strokes on one element, from the beta.

It entered Studio beta in April 2026 and was fully released in May 2026.
