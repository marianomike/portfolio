The Style Editor is a no-code tool in Roblox Studio that allows users a way to easily create and manage UI styles, design tokens and themes.

It shipped as a Studio beta in May 2025 alongside UI Styling, Roblox's CSS-inspired system for declaring overrides to UI properties once and applying them across a whole interface, so how a UI looks is separate from how it's built.

## Styles, tokens and themes

- **Design** style sheets hold rules that target classes, tags, modifiers like corners and strokes, and states like hover.
- **Tokens** are shared values, like one named color used across many properties.
- **Themes** are swappable sets of values, like light and dark mode, that can also switch at runtime.
