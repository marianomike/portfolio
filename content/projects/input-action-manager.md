The Input Action Manager is a visual editor in Roblox Studio for building and auditing an experience's input. Instead of digging through the Explorer or code, creators see every context, action and per-platform binding in one table.

## What it does

- Create contexts, actions and bindings for each platform in one place, including several bindings per action and key combinations.
- Scan an experience's existing input setup into the grid, and stay in sync with the Explorer both ways.
- Flag actions missing a binding on a platform, and keys that conflict within a context.
- Filter by context or by device.

It shipped as a Studio beta in July 2026 on top of the Input Action System, which is fully released, so everything made with it works in live experiences.
