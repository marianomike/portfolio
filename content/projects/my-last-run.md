My Last Run is the only photo app built specifically for runners. It is the easiest way to create pictures from your runs stats. Connect to Apple Health to automatically pull run data from any compatible tracking app, including Garmin Connect, Nike Run Club, Strava, Runkeeper and more!

I'm a runner and like to share photos of my runs on various social networks. This is a personal project of mine used to help teach myself Xcode and Swift. I designed it in Sketch, Illustrator, and Photoshop and coded it with Swift 3 in Xcode. I've also open-sourced the code below.

## View on the App Store

You can view the source code here: https://github.com/marianomike/mylastrun
