Two long-requested UI capabilities, built into the engine.

## Shadows

UIShadow is a native 2D drop shadow for any UI element, with blur, color, transparency, offset and spread. An element can carry several shadows, and they never affect layout.

## Individual corners

UICorner can now round each corner on its own, while the original corner radius still sets all four at once.

Both were announced in May 2026 and fully released in June 2026, ready to publish in live experiences.
