Run Visuals is an iOS and Android app that turns your runs into 3D. Every route from Strava, Garmin or Apple Health is drawn on its own terrain, with splits you can spin, an elevation profile, weather (sun, fog, clouds, rain or snow), your photo behind the run, and stickers for your stories. Each run keeps its own style, and anything you see can be shared as a post or a story, as an image or a video.

Version 2.0 is a full rebuild with a new brand, made in Unity for real-time 3D with Claude Code.

## Version 1.x

The first version made downloadable graphics, stickers and animated videos from the same running data, with photo templates styled as magazine covers, trading cards and framed prints. It was built with Claude Code + VS Code, Figma MCP, React Native and AWS.
